Trabajo Práctico 1: PowerShell

Módulo: Programación para Seguridad Informática

Docente: Lic. Carlos Pacheco

Objetivo

Obtener información sobre PowerShell, la política de ejecución, la edición del sistema operativo y los datos de la computadora.

Script de PowerShell

# Version de PowerShell
$PSVersionTable.PSVersion

# Politica de ejecucion
Get-ExecutionPolicy

# Informacion del sistema operativo
Get-ComputerInfo | Select-Object OsName, WindowsEditionId, OsVersion

# Informacion completa de la computadora
systeminfo

Descripción

El script permite consultar la versión de PowerShell, conocer la política de ejecución, identificar el sistema operativo y obtener información general del equipo.
